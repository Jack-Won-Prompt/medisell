# 관리자 매뉴얼 자료 (PPT 제작용)

## 파일 구성

| 파일 | 내용 |
|---|---|
| `admin-manual-script.md` | 슬라이드별 스크립트 — 캡쳐 파일명 · 영역 번호 설명 · 조작 순서 · 나레이션 · 주의사항 |
| `mobile-web-flow.md` | 모바일 앱 · 웹 연계 흐름 (부록 슬라이드 5장, mermaid 다이어그램 포함) |
| `images/` | 운영 화면 캡쳐 (영역 번호가 이미지에 이미 그려져 있음) |

## PPT 만드는 방법

1. 슬라이드 1장 = 스크립트의 `### S-NN` 항목 1개
2. `캡쳐`에 적힌 이미지를 슬라이드에 넣기 (번호 표시가 이미 포함돼 있어 도형을 추가로 그릴 필요 없음)
3. `표시 영역`의 번호별 설명을 이미지 옆에 글머리표로 넣기
4. `나레이션`을 발표자 노트에 붙여넣기
5. `주의`는 빨간 글씨 또는 주의 아이콘과 함께 배치

## 캡쳐 규격

- 촬영 환경: 운영 사이트(`www.medisell.co.kr`) 관리자 화면, 브라우저 1600 × 1400
- 영역 표시: 빨간 사각형 + 원형 번호 (요소 위치를 실제로 계산해 그림)
- **개인정보 처리**: 주문자 · 입금자 · 받는분 · 연락처 · 주소가 보이는 영역은 흐림(블러) 처리함

## 캡쳐 진행 상황 — **26장 전량 완료**

관리자 메뉴 22개 + 상세/폼 화면까지 모두 촬영했습니다. 미완 항목 없음.

| 그룹 | 파일 |
|---|---|
| 시작하기 | `03-login` `04-admin-layout` |
| 주문 처리 | `05-dashboard` `06-orders-index` `07-order-show` `10-bank-deposit` `11-cashbacks` |
| 상품 등록 | `13-category-form` `14-brand-form` `15-product-form` `17-product-imagesearch` |
| 회원·거래처 | `18-users-index` `19-user-show` `20-accounts` `21-login-logs` |
| 전시·프로모션 | `22-banners` `23-ads` `24-coupons` `25-coupon-issue` |
| 고객 응대 | `26-chat` `27-inquiries` `28-reviews` |
| 설정·자료 | `29-settings` `30-reports` |
| 부가 기능 | `31-push` `32-coupang` |

일부 슬라이드는 한 이미지를 공유합니다(예: S-08 주문상태 · S-09 송장은 `07-order-show.png` 의 ③ · ④ 영역 확대).
