- 사용법: 슬라이드 1장 = 아래 항목 1개. `캡쳐` 파일을 슬라이드에 넣고, `표시 영역`의 번호를
  이미지 위 도형(빨간 사각형 + 원형 번호)으로 얹은 뒤, `나레이션`을 발표자 노트에 붙여 넣으면 됩니다.
- 총 슬라이드: 표지 1 + 본문 32 + 부록(모바일 연계) 5 = **38장**
- 모바일 연계 부록은 `mobile-web-flow.md` 참조

## 1장. 매일 하는 일 — 주문 처리 (7장)

### S-05. 대시보드로 오늘 현황 파악하기

- **표시 영역**
  - ① 요약 카드(오늘 주문/매출 등) — 숫자를 클릭하면 해당 목록으로 이동
  - ② 최근 주문 목록
  - ③ 처리 대기 항목(입금대기·미답변 문의 등)

- **나레이션**
  > 아침에 관리자 화면을 열면 이 대시보드가 먼저 나옵니다. 오늘 들어온 주문과 처리해야 할
  > 항목이 요약돼 있어, 숫자를 클릭하면 곧바로 그 업무 화면으로 넘어갑니다.

### S-06. 주문관리 — 목록 보기
- **캡쳐**: `images/06-orders-index.png`
- **표시 영역**
  - ① 상태 탭 — 전체 / 입금대기 / 입금확인 / 상품준비중 / 배송중 / 배송완료 / 취소
  - ② [CSV] — 현재 목록을 엑셀로 내려받기
  - ③ 검색창 — 주문번호 · 주문자 · 입금자로 검색
  - ④ 주문 목록 — 행 오른쪽 [상세] 버튼으로 이동
  - ⑤ 페이지 번호
- **화면 설명**: 웹·앱에서 들어온 모든 주문이 한 곳에 표시됩니다.
- **조작 순서**
  1. 상태 필터에서 **입금대기** 선택 → 처리할 주문만 골라 보기
  2. 주문 행 클릭 → 상세 화면
- **나레이션**
  > 주문관리는 하루에 가장 많이 쓰는 화면입니다. 위쪽 상태 필터로 '입금대기'만 걸러 보면
  > 지금 처리해야 할 주문만 보입니다. 앱에서 들어온 주문도 여기 함께 나옵니다.
- **주의**: 주문번호는 `MS + 날짜 + 5자리`(예: MS260728A1B2C) 형식입니다. 고객 문의 시 이 번호로 검색하세요.

### S-07. 주문관리 — 상세 화면
- **캡쳐**: `images/07-order-show.png`

  - ② 배송 / 결제 정보 — 받는분·연락처·주소 (캡쳐에서는 개인정보 가림 처리)
  - ③ 주문 상태 변경
  - ④ 배송 / 송장
  - ⑤ 전자세금계산서
  - ⑥ 결제 / 취소 — 결제수단 표시
- **나레이션**
  > 주문 하나를 클릭하면 이 상세 화면이 나옵니다. 위에서부터 누가·무엇을·얼마에 주문했는지 보이고,
  > 아래쪽에서 상태 변경과 배송정보 입력을 하게 됩니다.

### S-08. 주문 상태 변경 — 가장 중요한 규칙
- **캡쳐**: `images/07-order-show.png` 의 **③ 영역**을 확대해 사용
- **표시 영역**
  - 현재 상태 배지 → 상태 선택 드롭다운 → [상태 변경] 버튼 → [목록으로]
- **상태 6단계**: 입금대기 → 입금확인 → 상품준비중 → 배송중 → 배송완료 / (취소)
- **자동으로 함께 처리되는 것**

  | 변경 | 시스템이 자동으로 하는 일 |
  |---|---|
  | → **입금확인** | 구매 적립금 지급, 구매 대행자 캐쉬백 적립 |
  | → **취소** | 재고 복구, 적립금 정산, 사용 쿠폰 복원, 캐쉬백 무효화, **토스 결제건은 자동 환불** |

  > 화면에도 같은 안내가 표시됩니다: `'입금확인' → 적립금 자동지급 / '취소' → 재고복구·적립금정산·(토스결제 시) 자동환불`
- **나레이션**
  > 상태를 '입금확인'으로 바꾸면 적립금 지급까지 자동으로 처리됩니다. 반대로 '취소'로 바꾸면
  > 재고와 적립금, 쿠폰이 모두 원래대로 되돌아갑니다. 그래서 상태 변경은 반드시 실제 상황과
  > 맞을 때만 눌러 주세요. 특히 취소는 되돌리기 어렵습니다.
- **주의**: 입금확인은 **1회만** 적립됩니다. 실수로 취소했다가 다시 입금확인하면 적립금 흐름이 어긋날 수 있으니
  고객센터 기록을 남기세요.

### S-09. 배송정보 입력
- **캡쳐**: `images/07-order-show.png` 의 **④ 영역**을 확대해 사용
- **표시 영역**
  - ① 택배사 선택 — CJ대한통운 · 한진택배 · 롯데택배 · 우체국택배 · 로젠택배 · 쿠팡
  - ② 송장번호 입력
  - ③ [송장 등록(배송중)] 버튼
- **조작 순서**
  1. 택배사 선택 → 송장번호 입력
  2. [송장 등록(배송중)] 클릭 — **이 버튼 하나로 송장 저장과 상태 변경(배송중)이 함께 처리됩니다**
- **나레이션**
  > 송장번호를 입력하고 상태를 배송중으로 바꾸면, 고객은 앱과 웹에서 배송조회를 할 수 있습니다.
  > 송장번호 없이 배송중으로만 바꾸면 고객이 조회를 못 해 문의가 들어옵니다.

### S-10. 입금확인 — 무통장 입금 대조
- **캡쳐**: `images/10-bank-deposit.png`
- **표시 영역**
  - ① 계좌 입금내역 수집 영역
  - ② [입금내역 수집 + 자동확인] — 내역을 가져오면서 이름이 맞는 주문을 자동 연결
  - ③ [미매칭 재매칭 실행] — 남은 건을 다시 한 번 자동 대조
  - ④ 입금 내역 표 — 거래일 · 입금자 · 입금액 · 매칭 · 수동확인
- **조작 순서**
  1. [입금내역 수집 + 자동확인] 클릭
  2. 매칭되지 않은 건이 남으면 [미매칭 재매칭 실행]
  3. 그래도 남으면 표 오른쪽 **수동확인**에서 해당 주문을 직접 지정
- **나레이션**
  > 무통장 입금은 이 화면에서 처리합니다. 먼저 계좌내역을 수집하고 자동매칭을 누르면
  > 입금자명이 같은 주문은 자동으로 연결됩니다. 이름이 달라 남은 건만 직접 골라 주시면 됩니다.
  > 매칭이 되면 해당 주문은 자동으로 '입금확인' 상태가 됩니다.
- **주의**: 입금자명이 주문자와 다른 경우(가족·법인 명의)가 자동매칭에서 남습니다. 금액과 날짜를 함께 보고 연결하세요.

### S-11. 대행 캐쉬백 정산

  - ② 상태 필터

- **주의**: 정산 버튼은 '지급했다'는 기록만 남깁니다. 실제 송금은 별도로 진행하세요.

## 2장. 상품 등록하기 (6장)

### S-12. 등록 순서 — 카테고리 → 브랜드 → 상품
- **캡쳐**: 없음 (흐름도 슬라이드)

- **나레이션**
  > 상품을 등록하기 전에 그 상품이 들어갈 카테고리가 있어야 합니다. 브랜드는 선택 사항입니다.
  > 이 순서만 지키면 상품 등록에서 막히지 않습니다.

### S-13. 카테고리 등록
- **캡쳐**: `images/13-category-form.png`
- **표시 영역**

- **캡쳐**: `images/06-orders-index.png` 의 **② [CSV]** 영역과 `images/18-users-index.png` 의 **① [CSV]** 영역
- **화면 설명**: 별도 메뉴가 아니라 **주문관리·회원관리·상품 목록 화면의 [CSV] 버튼**으로 내려받습니다.
- **나레이션**
  > 정산이나 보고용 자료는 각 목록 화면 오른쪽 위 CSV 버튼으로 내려받습니다.
  > 필터를 걸어 둔 상태로 누르면 그 조건의 자료만 저장됩니다.

## 7장. 부가 기능 (2장)

### S-32. 푸시 알림 발송
- **캡쳐**: `images/31-push.png`
- **표시 영역**
  - ① 제목 ② 내용 ③ 이동 경로(선택) ④ 대상 ⑤ 대상 이메일 ⑥ [발송]
- **조작 순서**
  1. 제목·내용 입력
  2. 필요하면 이동 경로 입력 (예: `/product/상품슬러그` — 알림을 누르면 그 화면으로 이동)
  3. 대상 선택 후 [발송]
- **나레이션**
  > 앱을 설치하고 알림을 허용한 회원에게 푸시를 보냅니다. 이동 경로를 넣으면 고객이 알림을
  > 눌렀을 때 해당 상품 화면으로 바로 들어갑니다. 특정 회원에게만 보내려면 대상 이메일을 지정하세요.
- **주의**: 발송한 알림은 취소할 수 없습니다. 문구를 두 번 확인하세요.

### S-33. 쿠팡 경쟁가 조회
- **캡쳐**: `images/32-coupang.png`
- **표시 영역**
  - ① 제품 선택 / 키워드 검색 — 우리 상품을 고르거나 검색어를 직접 입력
- **화면 설명**: 화면 상단에 현재 연동 상태(실연동 · 쿠팡 파트너스)가 표시됩니다.
- **나레이션**
  > 우리 상품과 타사 판매가를 비교해 보는 참고 화면입니다. 제품을 고르면 그 상품명으로
  > 검색해 경쟁가를 보여줍니다. 가격 정책을 검토할 때 참고용으로만 쓰세요.
- **주의**: 조회 결과는 외부 검색 기준이라 실제 판매 조건(배송비·수량)과 다를 수 있습니다.
